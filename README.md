# Alt Mobility Data Analysis

## Project Structure
- `sql/`: All MySQL setup and analysis queries
- `powerbi/`: Power BI dashboard file
- `visuals/`: Exported visualizations

## How to Reproduce
1. Run SQL scripts in MySQL Workbench
2. Open Power BI file and refresh connection
3. See analysis results in dashboard

## Key Findings
- Customer retention drops to 40% by month 3
- UPI payments have 20% failure rate
- Top 20% customers generate 60% revenue
